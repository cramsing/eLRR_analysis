# eLRR_analysis
Code and data for Plant Cell Surface Immune Receptor Mimicry and Antagonism 


Antagonism_review.xlsx is a good first overview file. Sheet 1 "eLRR" describes all the included eLRRs and what paper they were found in. 

Figure2.md walks through all the code used to make Figure2B and C. All accompanying files are described.
